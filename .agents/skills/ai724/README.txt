ai724 skill - portable bundle
1. Copy the folder "ai724" to <other project>/.claude/skills/ai724/   (or ~/.claude/skills/ai724/)
2. Give it credentials, either:
   a) set env vars AI724_API_KEY and AI724_REFRESH_TOKEN, or
   b) copy ai724-credentials.env to <skill>/.secrets/ai724.env
ai724-credentials.env is a SECRET (refresh token for the test account). Do not commit it or share it.

# Skills workspace

## Conventions

- Agent skills live under `.agents/skills/<skill-name>/SKILL.md` (per user instruction, not `.devin/`).
- `from-template/` holds sample template files used for testing the create-from-template skill.

## README maintenance

- After creating a new skill or updating an existing one, update `README.md` in the same change: add/refresh its row in the Skills table (name, link to SKILL.md, one-line description).
